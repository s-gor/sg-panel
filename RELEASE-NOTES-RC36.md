# SG-Panel v0.10.0 RC36

RC36 — срочный HTTPS hotfix поверх RC35.

## Исправлено

После успешного выпуска сертификата Let's Encrypt переключение панели с HTTP на HTTPS могло завершиться ошибкой:

```text
configure-https.sh: line 305: BACKUP_DIR: unbound variable
```

Функция проверки локальной HTTPS-заглушки использовала переменную `BACKUP_DIR`, которая принадлежала вызывающему скрипту и не передавалась в `configure-https.sh`. Из-за `set -u` выполнение прекращалось до первого запроса `curl`, после чего панель откатывалась на HTTP.

Теперь проверка:

1. самостоятельно создаёт одноразовый файл через `mktemp`;
2. проверяет настоящий адрес `https://$DOMAIN/` и сигнатуру SG-заглушки;
3. удаляет временный файл как при успехе, так и при ошибке;
4. не зависит от `BACKUP_DIR` или других переменных вызывающего процесса.

Сертификаты, уже выпущенные до ошибки RC35, остаются пригодными. Все функции RC35 сохранены.
