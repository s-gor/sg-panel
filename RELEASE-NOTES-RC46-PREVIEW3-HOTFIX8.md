# SG-Panel v0.10.0 RC46 Preview 3 Hotfix 8

Hotfix 8 исправляет фактическую причину, по которой карточка выбранного клиента после Hotfix 7 могла оставаться прежней узкой боковой панелью.

## Clients

- Карточка выбранного клиента вынесена из двухколоночной сетки таблицы на уровень полноценного блока страницы.
- Даже старый закэшированный CSS больше не может вернуть карточку в узкую правую колонку.
- Для `app.css` добавлена отдельная ревизия Hotfix 8, поэтому браузер загружает новый файл стилей без зависимости от прежнего кэша версии RC46.
- Заголовок клиента, статус, метрики и действия увеличены до масштаба Network.
- `UUID / Auth` отображается в крупном моноширинном поле с отдельной кнопкой копирования.
- `Подписка` и `Комментарий` расположены в компактной двухколоночной сетке.
- `Сбросить трафик` перенесён в общую строку действий и больше не занимает отдельную строку под блоком «Дополнительно».
- Техническая подпись приведена к русскому виду `КЛИЕНТ №...`.

## Установка

Обновление по-прежнему сохраняет SQLite-базу, клиентов, токены, ноды, сертификаты и конфигурации Xray.
