ФОРМАТЫ

Один token — три формата

Token принадлежит конкретному устройству, а не всему клиенту.

Base64/sub/TOKENАктивные URI устройства.
Plain/sub/TOKEN?format=plainПо одной ссылке в строке.
SG Client JSON v2/sub/TOKEN?format=jsonУправляемый профиль с deviceId и deviceUuid.
!

Token является секретом. После перегенерации прежний URL сразу перестаёт работать.
