HTTP или HTTPS ?

Начальная установка работает по HTTP. Домен и сертификат можно добавить позже, когда сервер уже проверен.

{{ panel_access.mode|upper }}
Текущий адрес {{ panel_access.url }} Backend остаётся на 127.0.0.1:{{ panel_port }} и напрямую наружу не публикуется.
!

Для Let's Encrypt заранее откройте TCP 80. Клиенты по-прежнему используют порт 443, обычный HTTPS открывает локальную заглушку, а панель работает на выбранном отдельном порту.
