# SG-Panel v0.10.0 RC35

RC35 — небольшой, но важный установочный hotfix поверх RC34.

## Исправлено

При первичной установке по HTTP проверка локальной SG-заглушки выполнялась конвейером `curl | grep -q` при включённом `set -o pipefail`. После нахождения строки `grep -q` закрывал канал раньше, чем `curl` успевал завершить запись большого HTML-ответа. `curl` возвращал код 23 (`Failed writing body`), а установщик ошибочно запускал rollback.

Теперь HTTP- и HTTPS-проверки:

1. сохраняют ответ Nginx во временный файл;
2. отдельно проверяют наличие сигнатуры SG-заглушки;
3. не создают ложную ошибку записи и ложный откат.

Reality target и Reality SNI не являлись причиной этой ошибки. Все функции RC34 сохранены без изменений.
