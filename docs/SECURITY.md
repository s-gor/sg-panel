# Security

Раздел управляет доступом к веб-панели и публичным подпискам.

## Panel Access

Здесь меняются:

- HTTP или HTTPS;
- публичный hostname;
- публичный порт;
- домен Let's Encrypt.

Изменение выполняется отдельной задачей с живым журналом. Не закрывайте страницу до финального результата.

## Пароль администратора

После смены пароля все административные сессии завершаются. Повторно войдите с новым паролем.

Не используйте пароль SSH, почты или другого сервиса.

## Сессии

Можно:

- увидеть активные и завершённые сессии;
- завершить одну сессию;
- завершить остальные;
- завершить все, включая текущую.

Если доступ к браузеру или компьютеру был потерян, завершите остальные сессии и смените пароль.

## Тайм-аут сессии

Допустимый диапазон задаётся интерфейсом. Малое значение безопаснее, но может мешать длительной настройке. После изменения сохраните настройки и заново войдите при необходимости.

## IP allowlist панели

Разрешает административную часть только указанным IP или CIDR.

Примеры:

```text
203.0.113.10/32
192.168.1.0/24
```

Перед включением добавьте текущий адрес. Loopback разрешён всегда, поэтому доступ через SSH-туннель можно сохранить.

При динамическом внешнем IP строгий `/32` может неожиданно закрыть доступ.

## Публичные подписки

Отдельно задаются:

- разрешённые форматы;
- IP allowlist подписок;
- допустимые сети.

Allowlist панели и allowlist подписок независимы.

## Журнал входов

Показывает время, IP и результат последних попыток авторизации. Повторяющиеся ошибки с неизвестного адреса — повод ограничить порт панели и включить allowlist.

## Журнал администратора

Фиксирует важные изменения, результат и IP. Срок хранения задаётся в настройках.

## Рекомендуемая схема

Для публичного сервера:

1. SSH разрешён только с вашего IP;
2. панель работает по HTTPS на отдельном порту;
3. порт панели разрешён только с административных адресов;
4. backend `8080` закрыт;
5. активен IP allowlist или SSH-туннель;
6. у каждого устройства отдельный клиент;
7. токены подписок не публикуются.

## Доступ через SSH-туннель

Публичный порт панели можно закрыть и использовать туннель:

```bash
ssh -L 61443:127.0.0.1:61443 ubuntu@SERVER_IP
```

Затем откройте:

```text
http://127.0.0.1:61443
```

Для HTTPS имя сертификата может не совпасть с `127.0.0.1`; в таком случае используйте локальное разрешение домена или временно HTTP-доступ, настроенный для localhost.
