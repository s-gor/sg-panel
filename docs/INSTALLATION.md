# Установка SG-Panel по IP и позднее включение HTTPS

Версия `v0.10.0 RC21` устанавливается без обязательного домена и сертификата.

## 1. Где можно установить

- Amazon EC2;
- VPS;
- домашняя Ubuntu VM;
- Proxmox;
- VMware;
- VirtualBox;
- сервер в локальной сети.

Минимально:

```text
Ubuntu Server
1 vCPU
1 ГиБ RAM
```

При малом объёме RAM установщик создаёт swap 2 ГиБ.

Во время длительных этапов RC21 показывает точную строку AWG вида `[SG-Panel] [|] Этап (3 сек)`: один символ из `|/-\`, одна перезаписываемая строка и время выполнения. Командный вывод показывается только при ошибке.

## 2. Подготовьте порты

Для первого запуска достаточно:

| Порт | Протокол | Источник |
|---:|---|---|
| `22` | TCP | ваш IP |
| `443` | TCP | клиенты Xray |
| `61443` | TCP | ваш IP или локальная сеть |

Не открывайте:

```text
8080
8443
```

TCP `80` пока не нужен.

## 3. Запустите установку

```bash
sudo apt-get update && sudo apt-get install -y curl ca-certificates unzip && curl -fsSL https://raw.githubusercontent.com/s-gor/sg-panel/main/install-from-github.sh -o /tmp/install-sg-panel.sh && bash -n /tmp/install-sg-panel.sh && chmod 700 /tmp/install-sg-panel.sh && sudo bash /tmp/install-sg-panel.sh
```

## 4. Ответьте на вопросы

На EC2 установщик сначала обращается к IMDSv2 и предлагает публичный IPv4, а не внутренний адрес `172.31.x.x`.

Пример для EC2:

```text
Адрес Xray для клиентов (публичный IP или домен) [203.0.113.10]: Enter
Публичный HTTP-порт панели [61443]: Enter
Имя первого пользователя [sg-admin]: Enter
Reality target [www.bing.com:443]: Enter
Reality SNI [www.bing.com]: Enter
Пароль администратора панели: ********
```

Пример для домашней VM:

```text
Адрес Xray для клиентов (публичный IP или домен) [192.168.1.200]: Enter
Публичный HTTP-порт панели [61443]: Enter
```

Установщик не спрашивает домен панели и не запускает Certbot.

Дальше он показывает семь этапов. На интерактивном терминале строка обновляется зелёной вертушкой и после успеха заменяется на `[OK]`. Финальный блок всегда содержит точный адрес панели.

## 5. Откройте панель

```text
http://SERVER_IP:61443
```

Backend работает только на:

```text
127.0.0.1:8080
```

## 6. Проверьте службы

```bash
systemctl is-active xpanel-web
systemctl is-active xray
systemctl is-active nginx
cd /opt/xpanel-mvp && .venv/bin/python -m xpanel --version
```

Ожидается:

```text
active
active
active
xpanel 0.10.0-rc22
```

Порты:

```bash
ss -ltnp | grep -E ':443|:61443|:8080|:8443'
```

Для начального `RAW/TCP + REALITY`:

```text
Xray     0.0.0.0:443
Nginx    0.0.0.0:61443
SG-Panel 127.0.0.1:8080
```

## 7. Проверьте первого пользователя

```bash
sudo cat /root/sg-panel-first-user.txt
```

Импортируйте ссылку в клиент Xray и проверьте соединение.

## 8. Новый порядок изменения конфигурации

После входа в RC21 формы Inbound, Outbounds, Routing, DNS, пользователей и Xray Config требуют сначала нажать **«Проверить конфигурацию»**.

Проверка выполняется на временной копии SQLite и запускает `xray run -test`. Только после успешного результата становится доступна кнопка **«Сохранить и применить»**. Изменение любого поля аннулирует проверку.

Контекстные JSON доступны на страницах Inbound, Outbounds, Routing, DNS, WARP и Xray Config.

## 9. Включите HTTPS при необходимости

Подготовьте:

- DNS `A` на публичный IPv4;
- TCP `80` для Let's Encrypt;
- выбранный порт панели для своего IP.

В панели:

```text
Безопасность → Доступ к панели
```

Выберите:

```text
HTTPS + Let's Encrypt
```

Укажите домен и порт, нажмите **«Сохранить и применить»** и дождитесь журнала.

После переключения панель автоматически перенаправит браузер на:

```text
https://panel.example.com:61443/login
```

Текущая HTTP-страница кратко потеряет соединение, потому что Nginx уже начнёт ожидать HTTPS на том же порту. Страница задания распознаёт этот момент и открывает новый адрес. Кнопка ручного перехода остаётся на экране как запасной вариант.

## 10. Вернуться на HTTP

В том же разделе выберите HTTP, укажите IP или hostname и примените.

Сертификат на диске сохраняется, но публичный доступ к панели снова работает по HTTP.

При возврате с более старой HTTPS-установки браузер мог запомнить HSTS для прежнего домена. В этом случае открывайте HTTP-панель по IP или локальному hostname, либо очистите HSTS-запись браузера. Новая конфигурация RC21 не добавляет HSTS, чтобы переключение обратно на HTTP оставалось возможным.

## 11. SSH-туннель без публичного порта

Если порт панели закрыт снаружи:

```bash
ssh -L 61443:127.0.0.1:61443 user@SERVER_IP
```

В браузере:

```text
http://127.0.0.1:61443
```

## Если установка прервалась

Повторите ту же команду. Незавершённая установка снова откроет мастер.

## Обновление существующей HTTPS-установки

Повторный запуск установщика сохраняет:

- текущий HTTPS-домен;
- порт панели;
- сертификат;
- secure cookies;
- пользователей и SQLite;
- настройки Xray.

Обновление не переводит существующую HTTPS-панель на HTTP.

## Установка из ZIP

```bash
unzip SG-Panel-v0.10.0-RC21-GITHUB-SOURCE.zip
cd sg-panel-main
sudo bash deploy/ec2-first-install.sh
```
