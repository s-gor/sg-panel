# SG-Panel UI23 Repair4 · Final System 1

## Что исправлено

- три экспериментальных слоя Global Buttons Preview 1–3 больше не подключаются;
- неудачный `Routing Final Gateway Grid 1` больше не подключается;
- вместо них используется один финальный слой `fix40-ui23-repair4-final-system1.css`;
- обычные действия стали спокойными outline-кнопками, primary и выбранные состояния получили единую акцентную заливку;
- Cluster очищен от белой полосы и разорванной пустой секции;
- Routing показывает отдельно:
  - реально применённую схему;
  - новый выбор в форме;
  - финальный выход текущей схемы;
  - состояние использования WARP;
- нижняя панель проверки больше не фиксируется поверх контента;
- ошибка проверки явно сообщает, что новая схема не применена и продолжает работать прежняя;
- действия Routing располагаются в стабильном порядке `Direct · WARP · Block`;
- отсутствующий WARP/Block оставляет пустую позицию и не растягивает соседние кнопки;
- пресет «Весь интернет через WARP» использует:
  - локальную сеть через Direct;
  - доступные категории заблокированных ресурсов и рекламы через Block;
  - весь остальной трафик через WARP;
- если в GeoFiles нет необязательной категории Block или Ads, применение `all_warp` не блокируется: отсутствующее правило пропускается, финальный WARP остаётся активным;
- категорийные пресеты `ads_block`, `blocked_warp` и российские наборы продолжают проверяться строго.

## Что не изменялось

- Xray inbound и transport;
- клиенты и подписки;
- WARP-ключи и WireGuard JSON;
- SG-Node runtime;
- Cascade;
- транзакционная проверка полного Xray candidate, backup и rollback.
