# SG-Panel UI23 Repair4 — Routing Gateway Preview 1

Первый перенос структуры и логики Routing из принятой линии SG-Gateway 021 в SG-Panel.

## Что перенесено

- единая карточка выбранной конфигурации;
- пользовательские Direct / WARP / Block правила по доменам и IP;
- базовые схемы: всё Direct, блокировка рекламы, заблокированные ресурсы через WARP, весь интернет через WARP, пользовательская схема;
- локальная сеть;
- российская маршрутизация: выключено, только доменные зоны, сайты и IP;
- отдельные действия для заблокированных ресурсов, рекламы и остального трафика;
- фактический порядок сохранённых правил;
- сводка GeoFiles и WARP;
- обязательная проверка полного Xray candidate перед сохранением;
- применение через существующий транзакционный механизм SG-Panel с backup и rollback.

## Адаптация под SG-Panel

- используются только реально включённые Outbounds SG-Panel;
- доступны Direct, Block, активный WARP, Cascade и пользовательские Outbounds;
- отсутствующий или отключённый Outbound выбрать нельзя;
- пользовательские старые правила не удаляются;
- новая страница заменяет только собственные правила с `managed_by=sg-unified-routing`;
- GeoFiles не меняются автоматически;
- метаданные интерфейса хранятся отдельно и не попадают в Xray `routing`.

## Ограничения Preview 1

- применяется пока только к локальному Controller;
- выбор и удалённое применение на SG-Node ещё не добавлены;
- перенос общей модели в SG-Client ещё не выполнен;
- внешний вид является первым функциональным приближением и будет дорабатываться после проверки на живом сервере.
