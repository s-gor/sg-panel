# SG-Panel UI23 Repair4 — Global Buttons Preview 3 Outline

Текущая накопительная визуальная линия после Routing Gateway Preview 3 и Global Buttons Preview 2.

## Что изменено

- обычные текстовые кнопки на всех страницах стали прозрачными с единой окантовкой;
- hover даёт только лёгкую полупрозрачную подсветку;
- цветная заливка появляется у выбранного/активного элемента и во время нажатия;
- вкладки разделов и JSON-вкладки используют ту же систему;
- в Routing незаполненными остаются все невыбранные варианты;
- выбранная схема или действие Direct/WARP/Block/Cascade получает спокойную акцентную заливку;
- тёмная и светлая темы имеют одинаковую логику состояний;
- золотая окантовка у обычных светлых кнопок больше не используется;
- disabled-кнопки остаются видимыми, но приглушёнными.

## Не изменено

Backend, база данных, Xray, Routing candidate, GeoFiles, Outbounds, WARP, Cascade, XMUX, Hysteria2 Salamander, backup и rollback.
