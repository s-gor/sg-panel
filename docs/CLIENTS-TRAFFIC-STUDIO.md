# Clients & Traffic Studio

Раздел **Clients** объединяет управление пользователями Xray, выдачу конфигураций и долговременную статистику трафика.

## Что находится на странице

В верхней части отображаются четыре сводные карточки:

- состояние Xray и текущий Inbound;
- число активных и общее число клиентов;
- общий трафик по всем клиентам;
- текущая суммарная скорость.

Ниже находятся поиск, фильтры, сортировка, таблица клиентов и карточка выбранного пользователя.

## Поиск, фильтры и сортировка

Поиск работает по:

- имени;
- UUID/Auth;
- комментарию.

Фильтры:

- **Активные** — пользователь включён и срок не истёк;
- **Онлайн** — Xray сейчас подтверждает активное соединение;
- **Истекают** — срок закончится в течение семи дней;
- **Просроченные** — срок уже истёк;
- **Отключённые** — доступ выключен вручную;
- **Без срока** — дата окончания не задана.

Сортировка доступна по имени, последней активности, объёму трафика, сроку и времени создания.

## Создание клиента

Нажмите **«Добавить клиента»**.

Заполните имя и, при необходимости, комментарий. Срок можно задать одним из трёх способов:

- без срока;
- на 1, 7, 30, 90 или 365 дней;
- до точной даты и времени UTC.

Сначала нажмите **«Проверить конфигурацию»**. Панель создаст временную копию SQLite, сформирует итоговый `config.json` и выполнит `xray run -test`. Рабочая база и запущенный Xray на этом этапе не меняются.

После успешной проверки нажмите **«Создать и применить»**. SG-Panel создаст резервную копию, сохранит пользователя, применит конфигурацию и откроет страницу со ссылкой, QR-кодом и подпиской.

## Что означают показатели трафика

### Текущая сессия Xray

Сырые счётчики текущего процесса Xray. Они могут начаться заново после перезапуска службы или сброса внутренних счётчиков.

### Сегодня

Сумма прироста, который SG-Panel сохранил с 00:00 UTC текущего дня.

### Текущий месяц

Сумма дневных записей с первого числа текущего месяца по UTC.

### За всё время

Долговременный итог SG-Panel. Он хранится в SQLite и не исчезает после:

- перезапуска Xray;
- применения новой конфигурации;
- обновления SG-Panel;
- перезагрузки сервера;
- обнуления внутренних счётчиков Xray.

### Текущая скорость

Средний прирост байтов между двумя последними измерениями. Коллектор запускается примерно раз в минуту, поэтому это не мгновенный сетевой график, а спокойная оценка текущей нагрузки.

## Направления трафика

В интерфейсе используются направления относительно клиента:

```text
↓ сервер → клиент
↑ клиент → сервер
```

Внутри Xray они называются иначе:

```text
downlink = сервер → клиент
uplink   = клиент → сервер
```

## Как сохраняется статистика

Системный таймер:

```text
xpanel-traffic.timer
```

раз в минуту запускает:

```bash
/opt/xpanel-mvp/.venv/bin/python -m xpanel collect-traffic --online
```

Коллектор читает Xray Stats API, параллельно проверяет online-состояние клиентов, сравнивает текущие сырые значения с предыдущими и сохраняет только положительный прирост.

Если текущее значение меньше предыдущего, SG-Panel считает, что Xray был перезапущен или его счётчик был обнулён. Новый счётчик начинает новую сессию, но уже накопленная история не уменьшается.

## Online и последняя активность

**Online** означает, что Xray Stats API подтвердил активность пользователя во время последнего фонового измерения. Обычно состояние обновляется не реже одного раза в минуту; открытие страницы не запускает медленный последовательный опрос всех клиентов.

**Последняя активность** обновляется, когда:

- Xray показывает пользователя online;
- между измерениями увеличился uplink или downlink.

Offline не означает, что профиль отключён. Это только отсутствие подтверждённой активности в текущий момент.

## График за 14 дней

Карточка клиента показывает суммарный дневной трафик за последние 14 дней. Высота столбца рассчитывается относительно самого активного дня в этом периоде.

График не передаёт данные во внешние сервисы: все значения берутся из локальной SQLite.

## Сброс статистики

Можно сбросить:

- историю одного клиента кнопкой **Сбросить трафик клиента** в основной карточке выбранного клиента;
- историю всех клиентов кнопкой **Сбросить весь трафик** в верхней панели страницы Clients.

Обе операции требуют отдельного подтверждения. Сброс удаляет накопленные показатели **Сегодня**, **Месяц** и **За всё время**. Пользователь, UUID/Auth, ссылка, подписка и конфигурация не удаляются.

Сырая **Текущая сессия Xray** может остаться видимой, потому что Xray продолжает хранить её в своём процессе. SG-Panel устанавливает текущее значение как новую точку отсчёта и не добавляет старый объём повторно.

## Если статистика не появляется

Проверьте:

1. В **Xray Server → Xray Config** включена статистика Xray.
2. Xray работает.
3. API слушает локальный адрес, обычно `127.0.0.1:10085`.
4. Таймер активен:

```bash
sudo systemctl status xpanel-traffic.timer --no-pager
```

5. Последний запуск коллектора прошёл без ошибки:

```bash
sudo systemctl status xpanel-traffic.service --no-pager
sudo journalctl -u xpanel-traffic.service -n 50 --no-pager
```

Ручная проверка:

```bash
cd /opt/xpanel-mvp
sudo .venv/bin/python -m xpanel collect-traffic --online
```

Ожидаемый результат:

```text
Traffic snapshot: users=N, all-time=...
```

## Резервные копии

Долговременная статистика хранится в `panel.db`, поэтому входит в обычные резервные копии SG-Panel и восстанавливается вместе с пользователями и настройками.
