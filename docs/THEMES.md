# Темы SG-Panel

Документ относится к версии `v0.10.0-rc70`.

В панели доступны ровно две темы:

- **Графит**;
- **Латте**.

Системная тема удалена. SG-Panel не меняет оформление автоматически вслед за Windows, Linux, macOS или браузером.

## Графит

`Графит` — тема по умолчанию. Она использует общую палитру SG Client / SG-Panel.

Основные поверхности:

| Элемент | Цвет |
|---|---|
| фон приложения | `#0B121C` |
| верхняя панель | `#0E1723` |
| боковая панель | `#101B29` |
| основные карточки | `#111D2B` |
| мягкие поверхности | `#0F1A27` |
| приподнятые элементы | `#162438` |
| поля ввода | `#0E1926` |
| обычная граница | `#24364B` |
| усиленная граница | `#34506B` |
| основной текст | `#F4F7FA` |
| вторичный текст | `#8A9AAF` |
| акцент | `#35D69A` |

Зелёный акцент используется только для работающих, успешных и выбранных состояний.

![Тема Графит](assets/sg-panel-rc45-graphite.png)

## Латте

`Латте` — тёплая контрастная светлая тема для дневной работы. Она не является белой инверсией `Графита`: фон заметно темнее карточек, вложенные блоки отделены границами, а поля и кнопки не теряются на странице.

Основные поверхности:

| Элемент | Цвет |
|---|---|
| фон приложения | `#D8CEC2` |
| боковая панель | `#DED3C6` |
| основные карточки | `#EEE6DC` |
| вложенные поверхности | `#D8CCBE` |
| поля ввода | `#F2EADF` |
| обычная граница | `#B7AA9B` |
| основной текст | `#2A2723` |
| вторичный текст | `#6C6258` |
| акцент состояния | `#2F7A62` |
| основные кнопки | `#49372A` |

Зелёный используется для рабочего состояния, выбора и успешных результатов. Основные действия оформлены тёмным кофейным цветом, чтобы светлая тема оставалась контрастной и не выглядела белёсой.

## Переключение темы

Переключатель находится в верхней панели после входа и на странице авторизации.

Доступные значения:

```text
Графит
Латте
```

Новая установка открывается в теме `Графит`.

Внутреннее значение `light` сохранено для совместимости: пользователям не требуется заново выбирать тему после обновления.

Переключение темы не изменяет серверную конфигурацию, Xray, клиентов, подписки или сетевые настройки.
