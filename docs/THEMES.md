# Темы SG-Panel

Документ относится к версии `v0.10.0-rc45`.

В панели доступны ровно две темы:

- **Графит**;
- **Светлая**.

Системная тема удалена. SG-Panel не меняет оформление автоматически вслед за Windows, Linux, macOS или браузером.

## Графит

`Графит` — тема по умолчанию. Она использует общую палитру SG Client / SG-Panel.

Основные поверхности:

| Элемент | Цвет |
|---|---|
| фон приложения | `#0B121C` |
| верхняя панель | `#0E1723` |
| боковая панель | `#101B29` |
| основные карточки | `#111D2B` |
| мягкие поверхности | `#0F1A27` |
| приподнятые элементы | `#162438` |
| поля ввода | `#0E1926` |
| обычная граница | `#24364B` |
| усиленная граница | `#34506B` |
| основной текст | `#F4F7FA` |
| вторичный текст | `#8A9AAF` |
| акцент | `#35D69A` |

Зелёный акцент используется только для:

- работающего профиля;
- успешного состояния;
- выбранного режима;
- основной кнопки;
- коротких индикаторов и рамок.

Крупные поверхности не окрашиваются зелёным.

![Тема Графит](assets/sg-panel-rc45-graphite.png)

## Светлая

Светлая тема оставлена вторым рабочим вариантом для пользователей, которым нужен дневной интерфейс.

Она не включается автоматически и выбирается вручную. Тема сохраняется в браузере для следующего входа.

![Светлая тема](assets/sg-panel-rc45-light.png)

## Переключение темы

Переключатель находится в верхней панели после входа и на странице авторизации.

Доступные значения:

```text
Графит
Светлая
```

Новая установка открывается в теме `Графит`.

Ранее сохранённые значения обрабатываются так:

| Старое значение | Результат в RC45 |
|---|---|
| `system` | `graphite` |
| `dark` | `graphite` |
| неизвестное значение | `graphite` |
| `light` | `light` |

Переключение темы не изменяет серверную конфигурацию, Xray, клиентов, подписки или сетевые настройки.
