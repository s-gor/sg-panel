# Интерфейс SG-Panel и раздел System

## Навигация

Левое меню разделено на шесть областей:

| Раздел | Что находится внутри |
|---|---|
| `System` | Resources, Status & Services, Logs & Diagnostics |
| `Clients` | клиенты, трафик, ссылки и подписки |
| `Xray Server` | Inbound и Xray Config |
| `Network` | Traffic Rules, Outbounds и DNS |
| `Security` | доступ к панели, пароль, сессии и журналы |
| `Maintenance` | Backups и Updates: копии, восстановление, проверка версии, живой журнал и rollback |

В правой части верхней панели показываются версия, общее состояние системы, переключатель темы, справка и меню администратора.

## System → Resources

### Память

Круговой индикатор показывает структуру RAM. В центре крупно отображается фактическое потребление SG-Panel.

Состояние сервера определяется по `MemAvailable`. Файловый кэш Linux считается освобождаемой памятью и сам по себе не является критической нагрузкой.

Основные строки:

- **SG-Panel** — служба панели и дочерние процессы;
- **Xray** — процесс Xray;
- **Nginx** — веб-сервер и fallback;
- **Ядро Linux и сеть** — память ядра и сетевых структур;
- **ОС и остальные процессы** — прочие процессы;
- **Файловый кэш** — память, которую Linux может освободить;
- **Свободно** — немедленно свободная память.

### Системные показатели

Ниже показаны CPU, load average, диск, uptime и другие краткие показатели. Кнопка **«Обновить»** получает новый снимок без изменения конфигурации.

## System → Status & Services

Раздел показывает состояние основных компонентов и позволяет безопасно перезапустить разрешённые службы.

Проверяйте:

```text
xpanel-web
xray
nginx
xpanel-traffic.timer
```

Если Xray не активен, сначала откройте `Logs & Diagnostics`, а не нажимайте повторный restart несколько раз.

## System → Logs & Diagnostics

Журналы разделены по источникам:

- SG-Panel;
- Xray;
- Nginx;
- порты;
- `xray run -test`;
- диагностический отчёт.

Каждый большой блок закрыт по умолчанию. Открывайте только нужный журнал и используйте копирование при обращении за помощью.

## Состояние «Система в норме»

Зелёный общий статус означает, что базовые проверки панели, Xray и конфигурации прошли. Он не доказывает доступность каждого внешнего сайта или корректность отдельного клиентского маршрута.

После изменения Network дополнительно проверяйте реальный трафик клиента.
