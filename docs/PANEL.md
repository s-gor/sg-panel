# Интерфейс SG-Panel, Help и раздел System

Документ относится к версии `v0.10.0-rc80`.

## Навигация

Левое меню разделено на основные области:

| Раздел | Что находится внутри |
|---|---|
| `System` | Resources, Status & Services, Logs & Diagnostics |
| `Cluster` | Controller, карточки SG-Node, heartbeat, задания и первый профиль |
| `Cascade` | входной и выходной сервер, проверка, включение и возврат Direct |
| `Clients` | клиенты, трафик, ссылки и подписки |
| `Xray Server` | Inbound, конфигурация и дополнительные параметры |
| `Routing` | Traffic Rules, Outbounds, DNS и GeoFiles |
| `Security` | доступ к панели, пароль, сессии и журналы |
| `Maintenance` | резервные копии, обновления и rollback |
| `Help` | встроенная русская справка по всем основным сценариям |

В правой части верхней панели показываются имя и публичный адрес сервера, версия, общее состояние системы, переключатель темы, справка и меню администратора.

## Имя сервера и публичный адрес

В `System → Status & Services` отдельно отображаются:

- редактируемое имя сервера;
- нередактируемый публичный IP или домен.

Имя используется в шапке и схеме Cascade. Если имя не задано, панель использует нейтральное название. Публичный адрес не следует заменять Reality SNI или маскировочным доменом.

## Темы

Доступны две темы:

- **Графит** — основная тёмная тема;
- **Латте** — тёплая контрастная светлая тема.

Выбор сохраняется в браузере и не меняет серверную конфигурацию. Подробности: [Темы SG-Panel](THEMES.md).

## Встроенная Help

Раздел `Help` содержит видимые пошаговые инструкции, а не только обзор архитектуры.

В справке описаны:

- пять серверных профилей;
- REALITY и XTLS Vision;
- клиенты, ссылки и подписки;
- полная настройка Cascade;
- отключение, замена выхода и удаление Cascade;
- полная установка и подключение SG-Node;
- heartbeat, первый профиль, повторное подключение и журналы Node;
- Routing, WARP, DNS и GeoFiles;
- HTTPS, доступ к панели, резервные копии, обновления и диагностика.

Контекстные значки `?` на страницах `Cascade`, `Cluster`, карточке Node и других сложных разделах открывают соответствующий якорь Help.

## System → Resources

Показывает CPU, RAM, диск, uptime, load average и использование памяти основными компонентами.

Состояние RAM определяется по `MemAvailable`. Свободное место на диске не используется вместо значения доступной оперативной памяти.

## System → Status & Services

Раздел показывает:

- Xray;
- Nginx;
- SG-Panel;
- итоговый `config.json`;
- имя сервера;
- публичный адрес;
- управляемые systemd-компоненты.

Перезапуск нужен только при диагностике. Обычные изменения применяются на своих страницах через проверку и сохранение.

## System → Logs & Diagnostics

Журналы разделены по источникам:

- SG-Panel;
- Xray;
- Nginx;
- порты;
- `xray run -test`;
- диагностический отчёт.

Для SG-Node дополнительно используются журналы на самой Node:

```text
/var/log/sg-node-full-install.log
/var/log/sg-node-connect.log
journalctl -u sg-node-agent
journalctl -u sg-node-worker
journalctl -u xray
```

## Состояние «Система в норме»

Зелёный общий статус означает, что базовые проверки панели, Xray и конфигурации прошли. Он не доказывает корректность каждого внешнего маршрута.

После изменения Cascade, Routing, WARP или профиля дополнительно проверяйте реальное клиентское подключение и внешний IP.
