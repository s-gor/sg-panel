# С чего начать

Эта страница объясняет логику SG-Panel и показывает, в какой рубрике выполнять каждую задачу.

## Главная логика Xray

Настройка состоит из трёх связанных частей:

| Вопрос | Страница панели |
|---|---|
| Как клиент подключается к серверу? | **Xray Server → Inbound** |
| Какие выходы доступны серверу? | **Network → Outbounds** |
| Какой трафик направлять в каждый выход? | **Network → Traffic Rules** |

Внутри Xray путь трафика остаётся таким:

```text
Клиент → Inbound → Xray → Routing → Outbound → Интернет
```

`Routing` — внутреннее имя объекта Xray. В интерфейсе пользовательские правила находятся на странице **Traffic Rules**.

## Карта панели

### System

#### Resources

Первый экран панели. Показывает:

- циферблаты CPU load, RAM, swap и диска;
- память Xray и SG-Panel;
- uptime;
- состояние Xray;
- публичную точку подключения;
- текущие Inbound и Default Outbound.

#### Status & Services

Показывает состояние Xray, Nginx, SG-Panel и рабочего `config.json`. Здесь находятся диагностические перезапуски служб.

#### Logs & Diagnostics

Показывает один выбранный журнал в компактном окне с собственной прокруткой, TCP-порты и полный результат `xray run -test`.

### Clients

#### Clients

Здесь создаются учётные записи Xray. Для каждого пользователя доступны:

- отдельный UUID;
- срок действия;
- включение и отключение;
- прямая ссылка VLESS или Hysteria 2 в зависимости от Inbound;
- QR-код;
- редактируемый Users JSON.

#### Subscriptions

Здесь создаются персональные URL подписок.

```text
Прямая ссылка:  vless://...
Подписка:       http(s)://АДРЕС:ПОРТ/sub/ТОКЕН
```

### Xray Server

#### Inbound

Определяет способ входящего подключения:

- `RAW/TCP + REALITY`;
- `XHTTP + TLS`;
- `XHTTP + REALITY`.

UUID пользователей сохраняются при переключении профиля, но клиентские ссылки могут измениться.

#### Xray Config

Содержит:

- Current JSON — полный редактируемый JSON;
- Generated Config — фактически сформированный `config.json`;
- Runtime-параметры Xray;
- полный результат проверки.

### Network

#### Traffic Rules

Определяет:

- Default Outbound;
- порядок правил;
- выборочный WARP;
- блокировки;
- маршруты по доменам, IP, портам, протоколам и пользователям.

Xray использует первое совпавшее правило. Меньший приоритет выполняется раньше.

#### Outbounds

Содержит:

- `direct` — интернет через IP сервера;
- `blocked` — блокировка;
- `warp` — Cloudflare WARP;
- пользовательские VLESS-выходы.

Создание Outbound ещё не направляет через него трафик. Направление задаётся в **Traffic Rules**.

#### DNS

Управляет внутренним DNS Xray, серверами, hosts и расширенными DNS-параметрами.

### Security

Содержит:

- HTTP или HTTPS + Let's Encrypt;
- IP/hostname или домен панели;
- публичный порт панели;
- пароль администратора;
- активные сессии;
- IP allowlist;
- ограничения подписок;
- журнал входов.

### Maintenance

#### Backups

Создаёт и восстанавливает копии SQLite и рабочего `config.json`. В базе находятся UUID, Reality private key, WARP и токены подписок, поэтому храните копии как секретные данные.

## Единый порядок изменения конфигурации

Для форм и JSON действует один workflow:

```text
Изменить
  ↓
Проверить конфигурацию
  ↓
Временная копия SQLite + полный xray run -test
  ↓
Сохранить и применить
```

До успешной проверки сохранение заблокировано. Любое изменение после проверки требует повторной проверки. Автосохранения нет.

## Обычные сценарии

### Добавить пользователя

```text
Clients → Clients → Добавить пользователя
Проверить конфигурацию → Сохранить и применить → Ссылка / QR
```

### Выдать подписку

```text
Clients → Subscriptions → пользователь → Копировать URL
```

### Переключить основной протокол

```text
Xray Server → Inbound → выбрать профиль
Проверить конфигурацию → Сохранить и применить
```

### Включить весь трафик через WARP

```text
Network → Outbounds → создать WARP → проверить WARP
Network → Traffic Rules → весь трафик через WARP
Проверить конфигурацию → Сохранить и применить
```

### Направить один сайт через WARP

```text
Network → Traffic Rules → выбранные домены → WARP
Проверить конфигурацию → Сохранить и применить
```

### Включить HTTPS панели

```text
Security → HTTPS + Let's Encrypt → домен и порт → Сохранить и применить
```

Операция выполняется в отдельном живом журнале и после успеха открывает новый HTTPS URL.
