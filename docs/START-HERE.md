# С чего начать

Документ относится к версии `v0.10.0-rc80`.

## Новая установка SG-Panel

1. Выполните установку по документу [INSTALLATION.md](INSTALLATION.md).
2. Откройте адрес панели, показанный установщиком.
3. Войдите под созданным администратором.
4. В `System → Status & Services` задайте понятное имя сервера и проверьте публичный адрес.
5. Убедитесь, что SG-Panel, Xray и Nginx находятся в штатном состоянии.
6. Откройте `Clients`, выберите первого клиента и получите ссылку или подписку.
7. Проверьте реальное подключение до изменения Inbound, Routing, Cascade или Cluster.

## Основной порядок применения изменений

Любое изменение рабочей конфигурации выполняется так:

```text
Изменить параметры
→ Проверить конфигурацию
→ дождаться xray run -test
→ Сохранить и применить
→ проверить реального клиента
```

Простой выбор карточки или изменение поля не переключает работающий сервер до проверки и применения.

## Настроить Cascade из двух SG-Panel

Используйте две полные SG-Panel:

```text
Клиент → входной сервер → выходной сервер → Интернет
```

Порядок:

1. На выходном сервере: `Cascade → Сделать этот сервер выходом`.
2. Скопировать служебную ссылку.
3. На входном сервере: вставить ссылку и нажать `Подключить и проверить`.
4. После успешного IP-теста нажать `Включить Cascade`.
5. Пользователю выдать обычную ссылку из `Clients` входного сервера.

Полная инструкция, замена выхода, возврат Direct, удаление и ошибки: [CASCADE.md](CASCADE.md).

## Подключить SG-Node

Cluster использует пять шагов:

1. `Cluster → Скопировать команду полной установки SG-Node` и запустить её на чистой Ubuntu.
2. Нажать `Добавить подготовленную SG-Node`.
3. Создать карточку, скопировать отдельную команду подключения и запустить её на Node.
4. Дождаться Agent, Worker, heartbeat и состояния `В сети`.
5. Разрешить `64441/tcp` и нажать `Проверить и развернуть` для первого VLESS REALITY.

Полная инструкция, журналы, повторное подключение и ошибки: [MULTI-NODE.md](MULTI-NODE.md).
