# Ссылки, QR-коды и подписки

Для каждого клиента SG-Panel создаёт прямые ссылки и постоянную подписку.

## Прямая ссылка

SG-Panel сохраняет ссылки всех настроенных профилей. Активные ссылки содержат текущие параметры работающего Inbound-профиля:

- адрес и порт;
- UUID или Hysteria auth;
- transport;
- Reality или TLS;
- path/service name;
- SNI и fingerprint;
- имя профиля.

После смены Inbound, домена, порта, UUID или других параметров прямую ссылку нужно импортировать заново.

QR-код **«Прямая ссылка»** содержит тот же URI.

На странице клиента активные ссылки показаны отдельно от сохранённых неактивных. Неактивную ссылку можно скопировать, но до переключения профиля она не работает. Для Multi-Inbound панель показывает отдельную ссылку и QR-код каждого включённого экземпляра.

## Постоянная подписка

Подписка использует персональный случайный токен:

```text
https://PANEL_DOMAIN:PANEL_PORT/sub/TOKEN
```

Сам URL может не меняться после смены Inbound или UUID. Клиентское приложение получает актуальную конфигурацию при следующем обновлении подписки. В подписку входят только реально активные соединения; сохранённые неактивные ссылки не выдаются.

QR-код **«Постоянный URL»** содержит адрес подписки, а не саму VLESS/Hysteria-конфигурацию.

## Форматы подписки

Панель может выдавать поддерживаемые форматы, включая Base64 feed и прямое представление. Разрешённые форматы задаются в Security.

Используйте формат, который понимает выбранное клиентское приложение.

## Включение подписки

1. Откройте `Clients`.
2. Выберите клиента.
3. Нажмите **«Ссылка, QR и подписка»**.
4. Включите подписку, если она выключена.
5. Скопируйте URL или отсканируйте QR-код.

## Пересоздание токена

После пересоздания токена прежний URL немедленно перестаёт работать.

Используйте эту операцию, если ссылка попала постороннему человеку. Затем обновите URL во всех клиентских приложениях.

## Отключение подписки

Отключение подписки не отключает самого клиента. Уже импортированная прямая конфигурация продолжит работать, пока клиент включён и его UUID/Auth действителен.

## Защита ссылок

- не публикуйте URI и токены в открытых сообщениях;
- не вставляйте их в скриншоты;
- ограничьте подписки отдельным IP allowlist, если клиенты имеют предсказуемые адреса;
- используйте HTTPS для подписок через публичный интернет;
- пересоздайте токен при подозрении на утечку.

## Проверка в браузере

Открытие subscription URL в браузере должно вернуть данные без страницы входа. Ошибка `403` обычно означает отключённую подписку или IP allowlist. Ошибка `404` может означать старый токен.

## После смены Inbound

- прямая ссылка или набор прямых ссылок меняется;
- содержимое постоянной подписки меняется;
- сам URL подписки остаётся прежним, если токен не пересоздан;
- клиентское приложение должно обновить подписку.
