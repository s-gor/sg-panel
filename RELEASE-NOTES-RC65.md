# SG-Panel v0.10.0-rc65

RC65 собран на основе RC64 и исправляет идентификацию экземпляра панели.

## Исправлено

- В шапке на всех страницах постоянно показываются имя сервера и адрес Xray/панели.
- Значение по умолчанию: `SG-Panel · <публичный IP или домен>`.
- Пользовательское имя не скрывает адрес: `CC1 Frankfurt · 63.179.105.193`.
- Если пользователь уже включил IP в имя, повторения не будет.
- На странице System → Status & Services адрес показан отдельным нередактируемым полем рядом с именем.
- Страница входа показывает ту же идентификацию.

## Не изменялось

Cascade, WARP, Cluster, клиенты, UUID, ключи, сертификаты, Routing и SG Client не изменялись.

## Установщик

Чистый установщик RC65 сохраняет порядок RC64: зелёная вертушка видна с первой секунды запуска, установка системных компонентов и bootstrap выполняются до ввода параметров, технический вывод остаётся в журнале.
