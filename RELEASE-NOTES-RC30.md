# SG-Panel v0.10.0 RC30 — Hysteria 2, Clients & Traffic Studio

RC30 — крупное обновление SG-Panel после опубликованного RC9. Панель теперь можно установить и проверить по IP без заранее подготовленного домена, использовать Hysteria 2, а управление клиентами и их трафиком собрано в одном рабочем пространстве.

## Главное в RC30

### Hysteria 2 + TLS

- отдельный Hysteria Studio;
- работа поверх QUIC/UDP;
- создание и редактирование профиля Hysteria 2;
- проверка параметров до применения;
- QUIC-пресеты и настройка пропускной способности;
- port hopping и masquerade;
- ссылка подключения, QR-код и подписка;
- безопасное применение с резервной копией и автоматическим откатом.

### Установка сначала по IP

Для первой установки больше не требуются домен, DNS-запись и сертификат Let's Encrypt.

Панель запускается по HTTP на отдельном выбранном порту, а начальный `RAW/TCP + REALITY` использует публичный IP или hostname сервера. Домен и HTTPS можно включить позже в разделе **Безопасность → Доступ к панели**.

Порт `443/tcp` остаётся у Xray. Для Hysteria 2 используется выбранный UDP-порт.

### Clients & Traffic Studio

Раздел Clients полностью переработан:

- сводка состояния Xray, активных и online-клиентов;
- общий входящий и исходящий трафик;
- поиск, фильтры и сортировка;
- компактная таблица и подробная карточка выбранного клиента;
- срок действия, последняя активность и честное online-состояние;
- ссылка, QR-код, подписка, конфигурация и JSON в одном месте;
- создание клиента в аккуратном модальном окне.

### Долговременная статистика

Для каждого клиента отображаются:

- текущая сессия Xray;
- сегодня;
- текущий месяц;
- всё время;
- текущая скорость;
- график за 14 дней.

Коллектор раз в минуту получает счётчики Xray Stats API и сохраняет прирост в SQLite. Накопленная история не теряется после перезапуска Xray, обновления панели или перезагрузки сервера.

RC30 также безопасно активирует Stats API при обновлении существующей установки и проверяет его доступность.

### Сброс статистики

На странице Clients доступны две заметные операции:

- **Сбросить трафик клиента**;
- **Сбросить весь трафик**.

Обе требуют подтверждения. Сброс не удаляет клиента, UUID/Auth, ссылку, QR-код, подписку или конфигурацию подключения. Текущие счётчики Xray становятся новой точкой отсчёта.

## Новая установка и обновление

Используется одна и та же команда:

```bash
sudo apt-get update && sudo apt-get install -y curl ca-certificates unzip && curl -fsSL https://raw.githubusercontent.com/s-gor/sg-panel/main/install-from-github.sh -o /tmp/install-sg-panel.sh && bash -n /tmp/install-sg-panel.sh && chmod 700 /tmp/install-sg-panel.sh && sudo bash /tmp/install-sg-panel.sh
```

Не используйте `curl | bash`: мастер установки должен читать ответы с клавиатуры.

При обновлении сохраняются база SQLite, пользователи, UUID/Auth, ключи, подписки, сетевые настройки, режим HTTP/HTTPS и накопленная статистика. Перед изменениями создаётся резервная копия; при ошибке выполняется откат.

## Проверка после установки

```bash
cd /opt/xpanel-mvp
.venv/bin/python -m xpanel --version
systemctl is-active xpanel-web
systemctl is-active xray
systemctl is-active xpanel-traffic.timer
sudo .venv/bin/python -m xpanel collect-traffic --online --strict
```

Ожидается:

```text
xpanel 0.10.0-rc30
active
active
active
Traffic snapshot: users=..., all-time=...
```
