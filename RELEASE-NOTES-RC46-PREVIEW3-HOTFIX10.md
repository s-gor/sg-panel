# SG-Panel v0.10.0 RC46 Preview 3 Hotfix 10

Hotfix 10 содержит одну локальную UI-правку страницы маршрутизации.

## Исправлено

- Карточка «Правила маршрутизации» сохраняет прежние размеры и стандартные отступы SG-Panel.
- Группа `2 правил / Новое из JSON / Добавить правило` немного сдвинута влево от правой рамки.
- Промежуток между элементами группы уменьшен с 8 до 7 px.
- На мобильной компоновке поведение не изменяется.
- Для исключения старого CSS из кэша используется ревизия `preview3-hotfix10`.
