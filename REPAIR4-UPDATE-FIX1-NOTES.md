# SG-Panel UI23 Repair4 — Update Fix 1

Исправлена проверка обновлятора после распаковки SOURCE через `python3 -m zipfile -e`.

Причина: стандартный Python ZIP extractor сохраняет содержимое файлов, но создаёт shell-скрипты с режимом `0644`. Обновлятор ошибочно требовал executable-bit у `deploy/migrate-placeholder-404.sh`, хотя сам запускает миграцию явно через `bash`.

Исправление:

- проверяется наличие файла, а не executable-bit;
- добавлена `bash -n` проверка синтаксиса миграции;
- запуск миграции остаётся явным через `bash`;
- XMUX, интерфейс, Xray, база и пользовательские настройки не менялись.
