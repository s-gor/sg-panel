# SG-Panel v0.10.0 RC46 Preview 3 Hotfix 17

Унификация страницы Security с интерфейсом Network и Routing.

- Удалена узкая правая колонка «Текущие предупреждения» и огромная пустая область под ней.
- Четыре проверки доступа собраны в одну полноразмерную строку состояния.
- Предупреждение HTTP и команда SSH tunnel размещены в общей нижней области карточки.
- «Вход и сессии» и «Публичные подписки» оформлены отдельными полноразмерными карточками.
- Настройки подписок собраны в компактную адаптивную сетку.
- Технические термины оставлены на английском: Public access, Panel backend, IP allowlist, Listen, Secure cookie, X-Forwarded-For, Plain и JSON.
- Действия, статусы и пояснения остаются на русском языке.
- Страница использует рабочую ширину Network до 1540 px.
- CSS revision: `preview3-hotfix17`.
