# SG-Panel v0.10.0 RC46 Preview 3 Hotfix 20

## SG-Node Runtime

- Одноразовая команда подключения по-прежнему устанавливает только Agent и Worker и регистрирует ноду.
- На странице зарегистрированной ноды добавлена отдельная команда `02 · Установить Xray Runtime`.
- Runtime устанавливает Xray v26.5.9, но не запускает службу без рабочей конфигурации.
- Nginx не устанавливается для пилотного VLESS REALITY.
- Первое развёртывание разрешено при установленном Xray, даже если служба ещё `inactive` или `failed` из-за отсутствия конфигурации.
- Worker включает и запускает `xray.service` только после успешной проверки и атомарной установки первой конфигурации.
- При ошибке первого применения конфигурация удаляется, а служба возвращается в безопасное остановленное состояние.

UI revision: `preview3-hotfix20`.
