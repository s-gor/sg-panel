# SG-Panel v0.10.0 RC46 Preview 3 Hotfix 3

## Единый установщик для чистой EC2

Добавлен корневой `install.sh`, рассчитанный на чистую Ubuntu Server 24.04 LTS.

Порядок работы:

1. До любых изменений задаются пароль администратора, публичный порт панели,
   адрес Xray, имя первого клиента, Reality target и Reality SNI.
2. После подтверждения параметров ввод больше не требуется.
3. С зелёной живой вертушкой выполняются `apt update`, `dist-upgrade`, установка
   Nginx, Python, unzip и остальных зависимостей.
4. Загружается либо используется лежащий рядом точный ZIP SG-Panel.
5. Устанавливаются SG-Panel, Xray и systemd-службы.
6. Проверяются службы и локальная страница входа.
7. В конце выводится готовый адрес панели.

Скрипт читает вопросы через `/dev/tty`, поэтому остаётся интерактивным при
запуске через `curl ... | sudo bash`.

`install-from-github.sh` теперь использует тот же единый мастер.
