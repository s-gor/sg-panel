# SG-Panel v0.10.0 RC46 Preview 3 Hotfix 12

Небольшой цельный UI-hotfix завершает обсуждённые правки без изменения размеров существующих карточек.

- На странице клиентских ссылок добавлены явные действия «К списку клиентов» и «Создать ещё клиента».
- Переход «Создать ещё клиента» открывает существующее окно создания на странице Clients.
- Сохранённые неактивные ссылки получили отдельное коричнево-янтарное оформление в тёмной и светлой темах.
- У неактивных ссылок убрано зелёное оформление статуса и кнопки копирования.
- Предупреждение «Сейчас не работает» оформлено в стиле состояния «Требуется проверка».
- Сохранены широкая страница Clients из Hotfix 9 и безопасный правый отступ действий маршрутизации из Hotfix 11.
- CSS revision: `preview3-hotfix12`.
