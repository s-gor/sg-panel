# SG-Panel v0.10.0 RC46 Preview 3 Hotfix 9

Hotfix 9 исправляет неверный масштаб всей страницы Clients. В Hotfix 8 была расширена только карточка выбранного клиента, тогда как остальные блоки продолжали использовать старый контейнер шириной 1000 px.

## Clients

- Вся страница помещена в стандартный `ui-page ui-page-wide`, как Xray Server и Network.
- Рабочая ширина увеличена до общего лимита интерфейса 1540 px.
- Верхняя панель действий, сводные карточки, фильтры, таблица, карточка выбранного клиента и нижняя информационная строка используют одну ширину.
- Сводные карточки сохраняют четыре колонки на нормальном настольном экране.
- Увеличены высота строк таблицы, аватары, статусы, основной текст и кнопки действий.
- Верхние кнопки располагаются в одной строке при достаточной ширине.
- Блок выбранного клиента и «Дополнительно» сохранены в полноразмерном виде Hotfix 8.
- Для браузера добавлена новая ревизия CSS `preview3-hotfix9`.

## Установка

Обновление сохраняет базу данных, клиентов, подписки, токены, ноды, сертификаты и конфигурацию Xray.
