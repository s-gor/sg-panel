# SG-Panel v0.10.0 RC46 Multi-Node Preview 3 Hotfix 1

Исправлен сбой этапа «Создание резервной копии» при обновлении сервера без каталога `/etc/xpanel-mvp/warp`.

Причина: необязательная проверка каталога WARP была последней командой функции резервного копирования и возвращала код 1 при отсутствии каталога. При `set -e` это ошибочно считалось аварией обновления.

Теперь все необязательные пути копируются через явные `if`, а этап резервного копирования всегда возвращает успех после корректного завершения.
