# SG-Panel v0.10.0 RC46 Multi-Node Preview 3 Hotfix 2

Hotfix 2 исправляет доступность безопасного удаления пользователя в интерфейсе.

## Исправлено

- «Опасная зона — удалить пользователя» теперь находится прямо в основной карточке выбранного клиента на странице **Clients**.
- Перед удалением видны центральный сервер, количество удалённых нод, затрагиваемые развёртывания, ссылки и подписка.
- Для удаления требуется ввести точное имя пользователя.
- Состояние выполняющегося или ошибочного мультинодового удаления видно в карточке клиента.
- Прежняя страница **Изменить клиента** сохраняет тот же безопасный механизм как дополнительный путь.

Backend безопасного удаления не изменён: ноды очищаются отдельными заданиями с проверкой Xray и rollback, а запись удаляется только после успешной очистки Cluster.
