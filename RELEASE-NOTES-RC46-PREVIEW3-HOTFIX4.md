# SG-Panel v0.10.0 RC46 Preview 3 Hotfix 4

## Автоматическое определение публичного IPv4 EC2

Единый `install.sh` теперь до начала `apt update` определяет публичный IPv4 EC2 через cloud-init, локальные данные cloud-init и AWS IMDSv2.

При успешном определении установщик показывает:

```text
[SG-Panel] Публичный IPv4 EC2 определён автоматически: 203.0.113.10
Адрес панели и Xray (можно указать домен) [203.0.113.10]:
```

Нажатие Enter принимает найденный адрес. При необходимости вместо него можно ввести домен. Ручной обязательный ввод появляется только если автоматическое определение действительно не удалось.
