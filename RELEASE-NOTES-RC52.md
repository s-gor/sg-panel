# SG-Panel v0.10.0-rc52

RC52 исправляет структуру интерфейса RC51 и превращает Panel exposure из красивого статуса в понятный рабочий раздел с полной встроенной инструкцией.

## Xray Server

- отдельный пункт **Expert** удалён из бокового меню;
- большая карточка Expert & GeoFiles удалена со страницы Inbound;
- XHTTP Extra, FinalMask, ECH и certificate pinning перенесены во вкладку **Xray Server → Дополнительно**;
- вместо пустых значений показываются безопасные эффективные состояния: `Auto`, `{}`, `Off` и «Не применимо»;
- редактирование по умолчанию выключено и требует явного включения, проверки и успешного `xray run -test`;
- XTLS Flow объяснён как общая серверно-клиентская настройка;
- для новой установки VLESS REALITY + TCP используется рекомендуемый `xtls-rprx-vision`, но существующие установки и ссылки автоматически не меняются.

## Routing и GeoFiles

- раздел **Network** переименован в **Routing**;
- вкладки: Traffic Rules, Outbounds, DNS, GeoFiles;
- GeoFiles вынесены в отдельную вкладку после DNS;
- показываются фактические пути, размеры, SHA-256, даты и состояние проверки установленного комплекта Xray;
- смена источника остаётся validate-first с backup и rollback.

## Security → Panel exposure

- содержимое формы теперь зависит от выбранного режима;
- Direct не показывает предупреждения Proxy и Tunnel;
- Proxy показывает только hostname, HTTPS, поддерживаемый порт, Cloudflare edge и origin lockdown;
- Tunnel показывает hostname, имя Tunnel, `cloudflared`, Access и ручной шаг закрытия публичного порта;
- подтверждения переименованы так, чтобы не выглядеть автоматическими действиями;
- кнопка называется **«Сохранить режим и проверить готовность»**;
- значок `?` ведёт прямо в подробную главу Help.

## Help

Добавлена полноценная русская инструкция:

- архитектура браузер → публичный Nginx → backend `127.0.0.1:8080`;
- Direct through Nginx;
- Cloudflare Proxy и поддерживаемые HTTPS-порты;
- origin lockdown и безопасное использование `CF-Connecting-IP`;
- Cloudflare Tunnel + Access;
- точное значение полей, индикаторов и подтверждений;
- безопасный переход между режимами без потери доступа;
- выбор режима и диагностика типичных предупреждений.

SG Client в RC52 не изменяется.
