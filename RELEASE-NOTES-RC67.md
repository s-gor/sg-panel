# SG-Panel v0.10.0-rc67

RC67 возвращает Routing и Outbounds к понятному интерфейсу RC65, сохраняет подтверждённые исправления Cascade и российских WARP-пресетов и полностью перерабатывает светлую тему.

## Что изменилось

- Экспериментальная пользовательская форма HTTP/SOCKS и точечная карточка proxy удалены из интерфейса и конфигуратора.
- Routing снова показывает только основные правила, WARP, региональные пресеты и экспертный JSON без промежуточного proxy-сценария.
- Сохранены два российских WARP-пресета:
  - `geosite:tld-ru` — только российские доменные зоны;
  - `geosite:category-ru` + `geoip:ru` — российские сайты и IP.
- Сохранены исправления Cascade: резервное копирование ссылки через Clipboard fallback, компактные кнопки и пояснение роли выходного сервера.
- Светлая тема переименована в «Туман» и получила холодную светло-графитовую палитру без белых пустых поверхностей.
- Тёмная тема «Графит» не изменялась.


## Установщик

Самодостаточный установщик по-прежнему показывает зелёную вертушку с первой секунды запуска, завершает установку системных компонентов до ввода параметров и оставляет технический вывод в журнале.

## Совместимость обновления

Обновление с RC65/RC66 сохраняет клиентов, UUID, REALITY-ключи, сертификаты, Cascade, WARP, Routing, Cluster и managed profile v2. Если в RC66 успели создать экспериментальный proxy outbound, RC67 удаляет его служебную таблицу и связанные точечные правила, а выход по умолчанию безопасно возвращает на `direct`.
