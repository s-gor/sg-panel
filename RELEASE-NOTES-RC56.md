# SG-Panel v0.10.0-rc56

RC56 собран на основе `055-SG-Panel-RC55.zip`. Основная задача — рабочий и понятный выборочный маршрут российских сайтов через Cloudflare WARP.

## WARP Routing

- Условия разделены на два независимых поля: **Домены / Geosite** и **IP / GeoIP / CIDR**.
- Добавлен пресет **«Российские сайты через WARP»**:

```text
geosite:category-ru
geoip:ru
```

- Домены и IP сохраняются раздельно.
- SG-Panel создаёт два управляемых правила: доменное с приоритетом `40` и IP-правило с приоритетом `41`. Это обязательно, поскольку Xray объединяет разные поля одного правила логическим AND.
- В карточке WARP показываются фактически созданные правила, сеть и outbound.
- Выборочный режим допускает только доменные условия, только IP-условия либо оба типа одновременно.
- `geoip:` в доменном поле и `geosite:` в IP-поле блокируются с понятной подсказкой.

## GeoFiles и проверка

Перед сохранением кандидат по-прежнему проходит полный `xray run -test`. Если выбранной категории нет в активном `geosite.dat` или `geoip.dat`, панель показывает её имя и предлагает сменить источник в **Routing → GeoFiles** либо изменить условие. Рабочая конфигурация при ошибке не меняется.

## Обновление существующей установки

В `warp_settings` добавляется поле `selected_ips`. Существующие домены, WARP-учётные данные, режим маршрутизации и рабочие правила не сбрасываются. Старые установки продолжают работать без ручной миграции.

## Небольшое изменение Cluster

Заголовок «Подключение SG-Node без пропущенных шагов» заменён на **«Подключение SG-Node»**. Подзаголовок: **«Подготовьте сервер, добавьте его в Cluster и выполните подключение.»**

## Не изменено

- установка и подключение SG-Node;
- первый профиль Node на `64441`;
- REALITY, Vision и fingerprint существующих профилей;
- managed profile v2;
- пользователи, UUID, ключи и сертификаты;
- SG Client.
