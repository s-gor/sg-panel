# Global Buttons Preview 1

Visual-only cumulative step over Routing Gateway Preview 3.

All ordinary textual buttons on every SG-Panel page now use the exact material of
the active System / Resources section button:

- dark theme: `#58738d` surface, `#7892aa` border, white heavy label;
- light theme: the active Luxury Jade pressed gradient, champagne border and white label;
- one 10 px radius, one border weight, one font family and 800 weight;
- primary, secondary, ghost, warning, danger and toggle action buttons no longer introduce unrelated colour shades;
- section tabs, nested tabs, client action buttons and the SG-Gateway-style Routing controls use the same material;
- selected controls stay in the same palette and are distinguished by an inset ring;
- disabled controls stay visible with reduced opacity.

Icon-only controls, close buttons, sidebar navigation and status pills are not action-button text surfaces and are intentionally unchanged.

No backend, database, Routing, Xray, GeoFiles, WARP, XMUX or Salamander logic was changed.
