# SG-Panel v0.10.0-rc50

SG-Panel 050 добавляет управляемые экспертные параметры Xray и полноценный контроль источника GeoFiles. Это не набор пустых полей: значения проходят проверку на временной копии базы, итоговый `config.json` проверяется установленным Xray, а GeoFiles применяются только после отдельной проверки и резервного копирования.

## Expert Transport

Новый раздел **Xray Server → Expert & GeoFiles** содержит:

- XHTTP Mode: `auto`, `packet-up`, `stream-up`, `stream-one`;
- отдельный `Server Extra` и `Client Extra` для XHTTP;
- отдельный серверный и клиентский JSON FinalMask;
- проверка структуры FinalMask: `tcp`/`udp` arrays и `quicParams`;
- ECH: выключено, сгенерированный комплект, существующий комплект или DNS-источник;
- certificate pinning с расчётом SHA-256 действующего TLS-сертификата;
- явные состояния «Не настроено», «Не применимо», «Настроено» и «Ошибка»;
- объяснение назначения, применимости, формата и риска каждого параметра;
- раскрываемые примеры, которые никогда не записываются в профиль автоматически.

`Server Extra` и серверная часть FinalMask попадают в рабочий Xray `config.json`. Клиентские части попадают в управляемый JSON-экспорт и, где это поддерживает формат VLESS URI, в параметры `extra`, `fm` и `pcs`.

Секретный `echServerKeys` никогда не включается в клиентский экспорт. В управляемый экспорт передаётся только клиентский `echConfigList`.

## GeoFiles

Добавлен выбор источника:

- сохранённый комплект установленного Xray;
- V2Fly;
- Loyalsoldier;
- RunetFreedom;
- два пользовательских HTTPS URL;
- два локальных файла.

Для активных `geoip.dat` и `geosite.dat` отображаются:

- источник;
- полный путь;
- размер;
- SHA-256;
- время изменения/получения;
- состояние последней проверки и применения.

Новый комплект сначала загружается в staging-каталог. SG-Panel запускает текущий управляемый `config.json` через `xray run -test` с выбранным каталогом ресурсов. Это выявляет повреждённые файлы и отсутствующие категории, используемые действующими Routing Rules.

Применение выполняется атомарно:

1. проверка неизменности SHA-256 после теста;
2. резервная копия текущих файлов;
3. атомарная замена;
4. повторная проверка конфигурации;
5. перезапуск Xray;
6. rollback при любой ошибке.

Комплект, установленный вместе с Xray, сохраняется отдельно при первом переключении и может быть выбран повторно.

## Экспорт

JSON-подписка получает секцию `managed` со схемой `sg-panel-managed-profile-v1`:

- текущий профиль и XHTTP Mode;
- Server/Client Extra;
- Server/Client FinalMask;
- применимость ECH и клиентский ECH Config;
- certificate pinning;
- источник, размеры и SHA-256 GeoFiles.

SG Client в этом релизе не изменяется. SG-Panel 050 уже формирует и хранит серверные и клиентские метаданные для следующего этапа интеграции.

## Ограничения

- ECH Xray применяется только к TLS, который завершается непосредственно в Xray. В текущей архитектуре XHTTP-TLS завершается в Nginx, поэтому ECH для него показывается как неприменимый к этой схеме.
- GeoFiles в RC50 управляются на Cluster Controller/локальном Xray. Автоматическое распространение комплекта на SG-Node в этот релиз не входит.
- Пользовательские URL принимаются только по HTTPS и задаются отдельно для `geoip.dat` и `geosite.dat`.
- SG-Panel не подставляет рекомендуемые примеры автоматически: экспертные параметры остаются выключенными, пока администратор явно не настроит и не проверит их.
