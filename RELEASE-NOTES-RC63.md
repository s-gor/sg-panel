# SG-Panel v0.10.0-rc63

RC63 собран на основе RC62. Функциональность панели не менялась; исправлен чистый самодостаточный установщик.

## Что исправлено

На некоторых новых Ubuntu 24.04 EC2 публичный IPv4 не определялся до вопросов мастера, потому что ранняя проверка могла зависеть от отсутствующего на чистой системе `curl`. Пользователь видел сообщение «Автоматически определить публичный IPv4 не удалось» и был вынужден вводить адрес вручную.

В RC63 мастер до установки пакетов использует системный Python и AWS IMDSv2. Дополнительно сохранены резервные способы через cloud-init, `checkip.amazonaws.com`, `api.ipify.org` и `curl`, если он уже доступен.

Ожидаемый вывод:

```text
[SG-Panel] Публичный IPv4 EC2 определён автоматически: 203.0.113.10
Адрес панели и Xray (можно указать домен) [203.0.113.10]:
```

## Запуск из любого каталога

Больше не предполагается, что пользователь называется `ubuntu` или что существует `/home/ubuntu`. Файл запускается из каталога, куда он загружен:

```bash
sudo bash ./063-INSTALL-SG-PANEL-RC63.sh
```

Зелёная вертушка `| / - \` по-прежнему появляется с первой секунды запуска. Отдельные `apt`, `curl`, `unzip` и ZIP панели не требуются.

## Что не менялось

- Cascade и имена серверов;
- WARP Routing;
- Cluster Controller и SG-Node;
- managed profile v2;
- SG Client;
- существующие пользователи, UUID, REALITY-ключи, сертификаты и маршруты.
