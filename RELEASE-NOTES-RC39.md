# SG-Panel v0.10.0 RC39

RC39 добавляет первый этап Multi-XHTTP: до трёх одновременных `XHTTP + TLS` Inbound в одном профиле.

## Архитектура

Все экземпляры используют один публичный адрес и один внешний `TCP/443`, который принимает Nginx. Разделение выполняется по уникальным XHTTP Path:

- основной — прежний Path и локальный `127.0.0.1:8443`;
- резервный — отдельный стабильный Path и `127.0.0.1:8444`;
- дополнительный — отдельный стабильный Path и `127.0.0.1:8445`.

Дополнительные локальные порты не нужно открывать в AWS Security Group или firewall.

## Совместимость

При обновлении с RC38:

- основной Path сохраняется;
- основной локальный порт сохраняется;
- UUID пользователей сохраняются;
- прежняя основная конфигурация подключения продолжает работать;
- второй и третий XHTTP выключены, пока администратор не включит их сам;
- настройки трёх Hysteria 2 Inbound остаются в базе и не изменяются;
- установленная через панель версия Xray не понижается.

## Ссылки и подписки

Каждый включённый XHTTP Inbound получает:

- собственный tag;
- собственный Path;
- собственный локальный listener;
- отдельную прямую ссылку;
- отдельный QR-код.

Одна постоянная подписка пользователя содержит все включённые XHTTP-ссылки, по одной в строке. Названия компактные: `пользователь · основной`, `пользователь · резервный`, `пользователь · дополнительный`.

## Защита от ошибок

Панель блокирует:

- одинаковые Path, включая различие только завершающим `/`;
- одинаковые локальные `listen:port`;
- неправильный Path;
- нечисловой или недопустимый локальный порт;
- публичный listen для включённого локального XHTTP listener;
- одинаковые названия экземпляров.

После изменения требуется обязательная проверка конфигурации и только затем применение.

## Ограничение первого этапа

RC39 запускает до трёх XHTTP одновременно внутри профиля `XHTTP + TLS`. Смешанный активный режим нескольких XHTTP и нескольких Hysteria в одном `config.json` в этот этап не входит: при переключении профиля настройки другой семьи сохраняются, но она не остаётся активной.
