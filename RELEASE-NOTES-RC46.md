# SG-Panel v0.10.0 RC46 — Cluster / Multi-Node Foundation

RC46 создаёт первый рабочий слой централизованного управления несколькими серверами. В интерфейсе он называется **Cluster**: центральная SG-Panel остаётся единственной веб-панелью, а на удалённых Ubuntu работают лёгкие SG-Node Agent и локальный Worker.

## Возможности текущего этапа

- карточки центрального сервера и удалённых SG-Node;
- роли, локации, назначение и online/offline;
- одноразовая регистрация и индивидуальный токен Agent;
- версии и состояние Agent, Xray и Nginx;
- CPU, RAM, диск, load average и последняя связь;
- пилотное безопасное развёртывание VLESS REALITY;
- удалённый `xray run -test`, резервная копия, атомарная замена и rollback;
- готовая клиентская ссылка после успешного применения;
- безопасное удаление пользователя с центрального сервера и связанных нод;
- отзыв и удаление сервера из Cluster без уничтожения Xray/Nginx на удалённой машине;
- фоновое обновление статуса без полной перезагрузки страницы;
- актуальное задание отдельно от сворачиваемой истории.

## Безопасность

Сетевой Agent работает без root. Привилегированный Worker не принимает сетевые подключения и выполняет только локальные задания через защищённый каталог. Каждая конфигурация проверяется по SHA-256 и через `xray run -test` до замены рабочего файла.

Если центральная панель недоступна, уже применённые Xray/Nginx продолжают работать самостоятельно.

## Ограничения

Текущий Preview автоматизирует только пилотное VLESS REALITY. XHTTP-TLS, Hysteria 2, Multi-Inbound, общая подписка, групповые обновления, балансировка и failover пока не включены.

## Совместимость

Обновление сохраняет пользователей, UUID, REALITY-ключи, Short ID, XHTTP Path, Hysteria auth, профили, сертификаты и клиентские ссылки центрального сервера.
