# RC46 Preview 3 Hotfix 21

Hotfix 21 полностью упрощает установку и подключение SG-Node.

- Один полный установщик SG-Node заменяет отдельные pre-install и runtime-этапы.
- Заранее устанавливаются Agent, Worker, Xray, Nginx, Certbot и системные зависимости.
- Одна команда подключения всегда заменяет прежнюю регистрацию автоматически.
- Успешное подключение подтверждается только после реально принятого heartbeat.
- В Cluster добавлены понятные действия «Скопировать установку», «Добавить ноду», «Создать команду подключения» и «Переподключить ноду».
- Технический параметр `--replace-registration` больше не требуется пользователю.
- Отдельная команда установки Xray Runtime удалена из основного интерфейса.
- Для первого профиля SG-Node по умолчанию используется TCP-порт `64441`.
