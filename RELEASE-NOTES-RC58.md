# SG-Panel v0.10.0-rc58

RC58 собран на основе `057-SG-Panel-RC57.zip`. Функциональность WARP Routing, подробная WARP-инструкция, Cluster, SG-Node и managed profile v2 сохранены. Основная задача релиза — окончательный единый установщик для чистой Ubuntu 24.04 и аккуратное ручное обновление.

## Чистая установка одним файлом

Для проверки до публикации используется один самодостаточный файл:

```text
058-INSTALL-SG-PANEL-RC58.sh
```

Команда:

```bash
cd /home/ubuntu
sudo bash 058-INSTALL-SG-PANEL-RC58.sh
```

Внутри уже находится точный исходный комплект RC58. Мастер не требует отдельного ZIP, предварительного `apt update`, установки `unzip` или ручной распаковки проекта.

## Порядок ввода

До системных изменений задаются все вопросы:

- пароль администратора и его повтор;
- публичный порт панели;
- публичный IP или домен Xray;
- имя первого клиента;
- Reality target;
- Reality SNI.

После принятия значений дополнительный ввод не требуется.

## Видимый прогресс

На экране показываются только шесть этапов:

1. подготовка системы;
2. обновление Ubuntu;
3. установка системных компонентов;
4. проверка и распаковка SG-Panel RC58;
5. установка SG-Panel, Xray и Nginx;
6. финальная проверка панели и служб.

Каждый этап имеет зелёную вертушку, время выполнения и итог `[OK]`. Сырые строки `apt`, `dpkg`, `curl`, `pip`, Xray, Nginx и `systemctl` не выводятся в терминал и сохраняются в журналах.

## Bootstrap после публикации

`install-from-github.sh` больше не запускает отдельный внутренний сценарий. Он:

1. тихо подготавливает загрузчик;
2. загружает `install.sh`;
3. проверяет синтаксис;
4. передаёт управление единому мастеру.

## Обновление и Rollback

`install-or-upgrade.sh` сохраняет приложение, SQLite, Xray config, WARP, доступ панели и systemd-файлы. При ошибке выводится отдельный этап:

```text
Rollback · восстановление предыдущего рабочего состояния
```

Он использует ту же зелёную вертушку и сообщает результат восстановления. Последние строки технического журнала показываются только при ошибке.

## Новая чистая установка

Новый Controller получает:

- SG-Panel `v0.10.0-rc58`, UI `sg058`;
- Xray `v26.5.9`;
- Nginx и Certbot;
- VLESS REALITY RAW/TCP на `443/tcp`;
- XTLS Vision;
- Firefox fingerprint для нового профиля;
- первого клиента и готовую VLESS-ссылку;
- HTTP-доступ к панели на выбранном публичном порту.

## Не изменено

- SG Client;
- managed profile v2;
- WARP Outbound и Routing RC56;
- подробная WARP-инструкция RC57;
- Cluster и SG-Node;
- существующие пользователи, UUID, ключи, сертификаты и сохранённые fingerprint при обновлении.

RC58 считается кандидатом до полного натурного прогона на новой EC2.
