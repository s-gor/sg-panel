# SG-Panel v0.10.0-rc57

RC57 собран на основе `056-SG-Panel-RC56.zip`. Логика WARP Routing из RC56 не изменена; релиз добавляет полную пошаговую документацию настройки и проверки.

## Что добавлено

- отдельный раздел справки `WARP: настройка и проверка`;
- точный порядок создания и проверки WARP Outbound;
- объяснение разницы между рабочим Outbound и применёнными Traffic Rules;
- пошаговое применение пресета `Российские сайты через WARP`;
- объяснение двух правил `geosite:category-ru` и `geoip:ru` и логики AND/OR Xray;
- инструкция добавления отдельного домена, Geosite, IP, GeoIP или CIDR;
- проверка таблицы правил с приоритетами 40 и 41;
- контрольный тест через временное правило `domain:ifconfig.me` с приоритетом 39;
- реальная проверка российского домена через `2ip.ru`;
- разбор ситуации, когда обычный IP-checker корректно показывает IP EC2;
- подсказки по GeoFiles, CDN, кэшу соединений и порядку правил.

## Интерфейс

- в карточке WARP Routing добавлена сворачиваемая инструкция;
- на странице Outbounds добавлена кнопка `Полная инструкция`;
- полное руководство доступно из контекстной справки Routing.

## Совместимость

- WARP Outbound и правила RC56 сохраняются без изменений;
- существующие пользователи, профили, ключи, GeoFiles и Cluster не изменяются;
- SG Client не изменяется.
