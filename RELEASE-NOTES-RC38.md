# SG-Panel v0.10.0 RC38

RC38 добавляет безопасное обновление Xray Core непосредственно из интерфейса панели.

## Что появилось

В `Maintenance → Updates` теперь раздельно отображаются и обновляются:

- SG-Panel;
- Xray Core.

Для Xray доступны два явно разделённых канала:

- **Stable** — только последний официальный стабильный релиз;
- **Pre-release** — только осознанный тест предварительной версии.

Предварительный канал никогда не включается автоматически.

## Безопасность обновления Xray

Перед заменой бинарника панель:

1. скачивает архив только из официального `XTLS/Xray-core`;
2. скачивает официальный файл `.dgst`;
3. сравнивает SHA-256;
4. проверяет точную версию бинарника из архива;
5. выполняет `xray run -test` с действующим `config.json`;
6. сохраняет прежний бинарник и копию конфигурации;
7. перезапускает Xray;
8. проверяет службу и все активные Inbound;
9. при любой ошибке выполняет автоматический откат и возвращает прежний Xray.

База SG-Panel, пользователи, ссылки, Nginx, HTTPS и сертификаты не изменяются.

## Совместимость с установщиком

После ручного обновления Xray через интерфейс последующие обновления SG-Panel не понижают его до встроенной рекомендуемой версии. Более новый установленный Xray сохраняется и проверяется.

RC38 основан только на рабочем RC37 Hotfix1 и сохраняет Multi-Hysteria, исправления HTTP RC35 и HTTPS RC36.

## RC38 Hotfix 4

- Подтверждение обновления SG-Panel и Xray разворачивается прямо внутри страницы; модальные и браузерные всплывающие окна не используются.
- Названия Hysteria 2 в клиентских URI сокращены до формата `пользователь · назначение`, поскольку протокол клиент показывает отдельно.
