# SG-Panel v0.10.0 RC37

RC37 добавляет первый безопасный этап Multi-Inbound: до трёх Hysteria 2 одновременно.

## Что добавлено

- основной Hysteria 2 Inbound на прежнем UDP-порту;
- резервный Hysteria 2 Inbound, по умолчанию `8443/udp`;
- дополнительный Hysteria 2 Inbound, по умолчанию `9443/udp`;
- отдельные название, tag, UDP-порт, персональный auth, ссылка и QR-код для каждого экземпляра;
- одна постоянная подписка со всеми включёнными Hysteria 2-ссылками;
- проверка конфликтов UDP-портов;
- диагностика каждого включённого UDP-listener.

## Совместимость

Основной Inbound сохраняет прежний UUID клиента как Hysteria auth, поэтому существующая основная ссылка не меняется, если не менялись домен и порт. Для второго и третьего Inbound SG-Panel создаёт отдельные стабильные auth.

Все три Inbound используют общие настройки Hysteria Studio: домен, TLS-сертификат, masquerade, congestion control и QUIC-параметры.

## Ограничение первого этапа

UDP port hopping можно использовать только при одном активном Hysteria 2 Inbound. Перед включением второго или третьего экземпляра диапазон port hopping нужно очистить.

Дополнительные порты необходимо отдельно разрешить в Security Group и firewall именно по UDP.

## Сохранённые исправления

RC37 включает исправление первичной HTTP-установки из RC35 и исправление переключения на HTTPS из RC36.
