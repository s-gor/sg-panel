# SG-Panel v0.10.0-rc53

RC53 вводит точный управляемый контракт между SG-Panel и SG Client. Серверно-зависимые значения больше не выглядят как набор полей, которые пользователь должен заполнить самостоятельно.

## Управляемый профиль SG Client v2

- JSON-подписка дополнена объектом `managedV2` со схемой `sg-panel-managed-profile-v2`;
- каждое активное соединение содержит собственную применимость транспорта, безопасности, REALITY/TLS, FinalMask и XHTTP;
- ответ указывает `managedPreferred: managedV2` и заголовок `X-SG-Managed-Profile: v2`;
- старый `managed` v1 сохранён для совместимости;
- на странице клиента появился отдельный готовый URL **SG Client · управляемый JSON v2**.

## REALITY

- Flow передаётся как серверно-управляемое значение и остаётся синхронизированным с URI;
- для REALITY управляемый профиль не содержит ECH, certificate SHA-256 и CA PEM;
- вкладка «Дополнительно» скрывает неприменимые TLS-поля вместо пустых или серых редакторов;
- SG Client получает явное указание, что Flow нельзя включать независимо от сервера.

## TLS

- добавлен автоматический или ручной `verifyPeerCertByName`;
- добавлен проверяемый импорт пользовательской CA/PEM с запретом закрытого ключа;
- сохраняются источник и SHA-256 импортированной цепочки;
- System CA остаётся включённым по умолчанию;
- certificate pinning передаётся только при наличии реального подтверждённого SHA-256;
- отсутствует опасный режим «получить с удалённого сервера и сразу доверять».

## ECH

- серверный `echServerKeys` остаётся только на Controller;
- клиент получает только связанную ECHConfig или проверенный DNS/DoH-источник;
- ECH показывается только для схемы, где TLS обрабатывает Xray;
- для TLS, завершаемого в Nginx, фиктивная ECH-настройка не экспортируется.

## FinalMask и XHTTP

- безопасные эффективные значения `Auto`, `{}` и `Off` сохранены;
- FinalMask остаётся единственным разрешённым экспертным override, но требует согласованных Server/Client JSON и полной проверки;
- XHTTP Server Extra и Client Extra передаются раздельно.

## Help и документация

- Help подробно описывает контракт SG-Panel → SG Client;
- добавлено объяснение REALITY/TLS, Flow, ECH, pinning, PEM и источников значений;
- добавлен отдельный документ `docs/SG-CLIENT-MANAGED-PROFILE.md`;
- URL JSON-профиля явно помечен как секретный token.

SG Client в архив RC53 не входит и не изменяется. RC53 подготавливает серверную сторону для совместной проверки импорта и поведения клиента.
