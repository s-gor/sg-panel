# SG-Panel v0.10.0-rc64

RC64 собран на основе RC63. Функциональность панели не менялась; переработан порядок чистой установки.

## Новый порядок

Установщик начинает работу с зелёной вертушкой `| / - \` с первой секунды запуска. до ввода параметров он:

1. проверяет Ubuntu 24.04 и права root;
2. ожидает завершения cloud-init и освобождения apt/dpkg;
3. обновляет Ubuntu;
4. устанавливает `curl`, `ca-certificates`, `unzip`, `rsync`, Python, SQLite, Nginx, Certbot, OpenSSL и остальные обязательные компоненты;
5. определяет публичный IPv4.

Только после этого мастер запрашивает пароль, порт панели, адрес Xray, имя сервера, первого клиента, Reality target и Reality SNI. После подтверждения установка продолжается без дополнительного ввода.

Такой порядок надёжнее на совершенно чистых EC2: определение IP и распаковка больше не зависят от того, какие утилиты случайно были предустановлены в конкретном образе Ubuntu.

## Видимый прогресс

Пользователь видит семь этапов:

```text
Этап 1/7 · Подготовка чистой Ubuntu
Этап 2/7 · Обновление Ubuntu
Этап 3/7 · Установка системных компонентов
Этап 4/7 · Определение публичного адреса
[ввод параметров]
Этап 5/7 · Проверка и распаковка SG-Panel RC64
Этап 6/7 · Установка SG-Panel, Xray и Nginx
Этап 7/7 · Финальная проверка панели и служб
```

Вывод `apt`, `dpkg`, `curl`, Python, Xray, Nginx и systemd записывается только в журналы.

## Запуск

```bash
sudo bash ./064-INSTALL-SG-PANEL-RC64.sh
```

Отдельный ZIP, предварительные `apt update`, `curl` и `unzip` не нужны.

## Что не менялось

- Cascade и имена серверов;
- WARP Routing;
- Cluster Controller и SG-Node;
- managed profile v2;
- SG Client;
- существующие пользователи, UUID, REALITY-ключи, сертификаты и маршруты.
